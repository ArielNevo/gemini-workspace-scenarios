# גלו איפה Gemini יכול לעזור בעבודה שלכם

> **אין להזין באתר הזה, בריפו הזה או בכלי עצמו מידע ארגוני, מידע אישי או מידע מוגן.** האתר לא מבקש ולא אוסף טקסט חופשי. הריפו פומבי, ולכן אין להוסיף אליו מידע פנימי מכל סוג, גם לא בהערות, בתרחישים או בהדגמות.

אתר סטטי בעברית שעוזר לעובדי הארגון שעדיין אין להם רישיון לגלות במה **Gemini** ו-**Gemini Notebook (לשעבר NotebookLM)** יכולים לעזור בעבודתם. העובד עונה על כמה שאלות בחירה, מקבל עד שלושה שימושים עם הסבר למה הוצעו, רואה הדגמה על מסמכים מדומים, ומקבל תוכנית להתנסות ראשונה ודרך לבקש גישה.

## עקרונות

- **גילוי לפני רישוי.** אין צורך בחשבון, ברישיון או בשרת.
- **הליבה בלי מודל שפה.** ההתאמה נעשית בכללים שקופים, בדפדפן.
- **כנות.** כל תרחיש מסמן מה ידוע אצל Google (עם מקור ותאריך), מה ייבדק עם הקצאת הרישיון, ומה טרם נבדק בארגון. כל התרחישים מתחילים כטיוטה.
- **אפס עלות ואפס צד שלישי.** GitHub Pages, בלי עוגיות, בלי אנליטיקה, בלי בקשות רשת חיצוניות.

## הרצה מקומית

```bash
npm ci
npm run dev
```

בדיקות: `npm run check` (כולל lint, טיפוסים, תוכן, בדיקות יחידה, build ובדיקת bundle) ו-`npm run test:e2e` (מסלול מלא, נגישות, הודעות "אין להזין").
